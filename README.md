# Exerra Heat Marketplace

Exerra is a HackATL 2026 team prototype exploring how data centers' excess heat could be matched with nearby buildings that need heat. The prototype combines a marketplace view with a technical and financial screening workflow for comparing potential matches.

## What the prototype demonstrates

- A marketplace map with fictional data-center and building profiles
- Rule-based screening using estimated heat availability, heat-pump efficiency, route distance, costs, savings, payback, and 25-year value
- Sensitivity analysis: change an assumption such as pipe cost and see how match rankings change
- A simulated introduction request flow; it does not contact any person or organization

## Run locally

Open `index.html` in a web browser. No server, package installation, or build step is required. An internet connection is used to load fonts; the rest of the prototype is included in the file.

## Technology

- HTML, CSS, and JavaScript
- Inline SVG for the map, diagrams, and charts

## Data and limitations

The data-center and building profiles and map locations are fictional demonstration data. Cost, energy, and engineering inputs are illustrative assumptions. The calculations are intended for preliminary screening and demonstration; they are not verified project estimates or engineering advice.

Although the interface uses the label “AI Feasibility,” its calculations are deterministic, rule-based formulas. The prototype does not use a trained machine-learning model or a live AI service. Supplier information and introduction requests are simulated.
